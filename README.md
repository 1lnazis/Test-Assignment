## Допущения и нефункциональные требования

В задании нет числовых требований, поэтому приняты допущения

- Нагрузка: чтение до 1000 RPS на инстанс, обновления единицы в секунду (ограничены квотами провайдеров)
- Чтение: p99 < 10 мс
- Свежесть: при доступном провайдере новое значение появляется в чтении через несколько секунд после запроса обновления
- Консистентность: eventual. Скорость чтения и доступность важнее строгой консистентности
- Развёртывание: один инстанс
- Валюты: USD, EUR, MXN, RUB, KZT
